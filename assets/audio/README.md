# Ambient Music Assets Guidelines
*Petal & Projector Audio System*

This directory houses the ambient background tracks for the cinematic movie journal.

## Default Track References (Configured in `audio.js`):
1. `track-1-cherry-blossom-reverie.mp3`: Soft piano, gentle reverb, warm ambient pads.
2. `track-2-celestial-projector.mp3`: Ethereal strings, subtle lo-fi tape hiss, celestial warmth.
3. `track-3-memories-in-velvet.mp3`: Acoustic fingerpicking and rain textures.

## Licensing Requirements:
- Use only royalty-free, Creative Commons Zero (CC0) or licensed music (e.g., from Free Music Archive, Pixabay Music, YouTube Audio Library).
- Do NOT bundle copyrighted film soundtracks directly.

## Built-in Procedural Ambient Synthesizer:
If MP3 audio files are not yet uploaded, the built-in Web Audio API generative synthesizer automatically creates a continuous, calming harmonic ambient pad with pentatonic chime frequencies, ensuring the music player works out of the box with zero missing asset errors!
